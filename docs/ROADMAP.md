#### المرشحون والقرار / Candidates and decisions

| مرشح / Candidate | القرار / Decision | السبب / Why |
|---|---|---|
| مساعد سمعة ملف/رابط (روابط VirusTotal العامة فقط، بدون مفتاح API) | **تُضاف** (`reputation`) | تكملة لفاحص البصمة: الحساب محليًا، والفتح في المتصفح فقط، بدون إرسال الملف من البرنامج |
| فك JWT | **تُضاف** (`jwt`) | حاجة يومية لفك الرأس والحمولة ورؤية الانتهاء، بدون تحقق توقيع (لا مفاتيح) |
| فك شهادة / طلب CSR | **تُضاف** (`certdecode`) | فاحص TLS الحالي يتصل بالمضيف؛ هذه الأداة تفسّر شهادة أو CSR ملصقة بدون شبكة |
| بحث WHOIS / RDAP | **تُضاف** (`rdap`) | RDAP عام وبدون مفتاح؛ بديل حديث لـ WHOIS لنطاق أو عنوان |
| عنوان IP العام والموقع التقريبي | **تُضاف** (`publicip`) | سؤال متكرر عند ضبط جدار ناري أو VPN؛ مصادر HTTPS معروفة وبدون مفتاح |
| تتبع المسار (traceroute) مع عرض القفزات | **تُضاف** (`traceroute`) | مشخّص الشبكة فيه تتبع نصي داخل تقرير أطول؛ هنا أداة مخصّصة بجدول قفزات وعرض بصري |
| عارض الاتصالات المفتوحة / المنافذ المستمعة (مثل netstat مع اسم العملية) | **لا** | موجودة أصلًا داخل «المنافذ والخدمات» (استماع + اتصالات قائمة + اسم العملية) |
| عارض برامج بدء التشغيل / الثبات (persistence) | **تُضاف** (`startup`) | فحص الصحة لا يعرض مفاتيح Run ومجلد Startup؛ العرض للقراءة فقط (بدون حذف) |
| ماحية ملفات / حذف آمن (file shredder) | **لا** | مؤجلة عمدًا لخطر الإنذار الكاذب من مضادات الفيروسات، حتى يتم توقيع الشيفرة (انظر أعلاه) |
| مولّد QR لشبكة Wi-Fi | **تُضاف** (`wifiqr`) | عملي لمكتب أو شبكة ضيوف: صيغة `WIFI:T:…` المعيارية |
| مولّد MAC/UUID عشوائي | مؤجّل (أولوية أقل) | مفيد للمختبرات لكن أضعف من التسعة المختارة؛ يمكن إضافته لاحقًا |
| مختبر تعبيرات منتظمة (regex) | **تُضاف** (`regex`) | عمل يومي لمديري الأنظمة عند فحص السجلات والقواعد، ويعمل بدون إنترنت |
| اختبار سرعة (speed test) | **لا** | لا توجد واجهة رسمية مجانية يمكن استخدامها بوضوح دون مخالفة شروط الخدمة |
| فاحص ملف Base64/Hex | **لا** (تغطية جزئية) | «ترميز وفك ترميز» يغطي النص؛ لا داعي لأداة منفصلة في هذا الإصدار |

- **الإصدار:** [desktop-v2.0](https://github.com/abdelaziz-maysara-hm/Tech-Insights/releases/tag/desktop-v2.0): `NetSecAtlasTools.exe` (x64) و`NetSecAtlasTools-arm64.exe` و`SHA256SUMS.txt` و`screenshots.zip`. نفس اسم الملف ونفس أسلوب الوسوم القديم، فرابط `releases/latest/download/NetSecAtlasTools.exe` ما زال يعمل.
- **التحميل من الموقع:** مباشر من نفس النطاق: `https://netsecatlas.com/downloads/NetSecAtlasTools.exe`. سير النشر ينسخ ملفات آخر إصدار إلى `/downloads/` ويعيد النشر تلقائيًا بعد أي إصدار `desktop-v*` ناجح.
- **الاختبارات قبل كل إصدار** (`.github/workflows/desktop-ci.yml`، على `windows-latest` و`windows-11-arm`): 67 اختبار وحدات، اختبار تشغيل (النافذة تظهر وتبقى تعمل، ووضع اللقطة يخرج بنجاح)، و32 اختبار واجهة FlaUI تفتح كل أداة وتشغّل مثالها وتتحقق من النتيجة، مع لقطات شاشة عربي وإنجليزي. الإصدار لا يُنشأ إلا إذا نجح كل ذلك.
- **مستودع netsecatlas-apps:** مذكور فيه أنه مستبدل، ومحفوظ للتاريخ. بطلب المالك في 23 نوفمبر: يُترك كما هو، **لا يُؤرشف**.
- **صفحات `/programs` غير المكتملة:** لم تُستكمل؛ صفحة `/tools` صارت صفحة البرنامج، و`/programs` و`/downloads` يحوّلان إليها. العمل غير المكتمل ما زال محفوظًا في `git stash` محليًا فقط.

### الخطوات التالية للبرامج

1. **مقال مرافق** (عربي + إنجليزي) يشرح البرنامج وأهم 5 أدوات، وروابط من المقالات القديمة ذات الصلة (البصمة، كلمات المرور، DNS، المنافذ، قفل الحسابات). مؤجل حاليًا بطلب المالك (لا مقالات الآن).
2. **إصدار desktop-v2.1 (تم في 27 نوفمبر 2026):** التفاصيل في [المرحلة المكتملة](#phase-2-1). الإصدار: [desktop-v2.1](https://github.com/abdelaziz-maysara-hm/Tech-Insights/releases/tag/desktop-v2.1). التحميل: `https://netsecatlas.com/downloads/NetSecAtlasTools.exe`.
2ب. **أداء الموبايل وتوسيع الفيديو (قيد التنفيذ):** الخطة وصناديق المتابعة في [المرحلة الحالية](#phase-perf-videos). المقالات ما زالت موقوفة.
3. **النشر على Microsoft Store** يحتاج حساب المالك (التسجيل للأفراد مجاني عبر [storedeveloper.microsoft.com](https://storedeveloper.microsoft.com)). التغليف المقترح: MSIX، والمتجر يعيد التوقيع فيزيل تحذير SmartScreen لمستخدمي المتجر.
4. **توقيع الشيفرة للتحميل المباشر:** غير متوفر حاليًا. Azure Artifact Signing للأفراد في الولايات المتحدة وكندا فقط، فالأنسب للمالك في مصر شهادة OV (~150–300 دولار/سنة). شهادات EV منذ 2024 لم تعد تتخطى SmartScreen فورًا. SignPath Foundation قد ترفض أدوات «المسح» مثل فاحص المنافذ. السمعة تُبنى مع الوقت حتى بعد التوقيع.
5. أدوات أُجِّلت عمدًا لارتفاع خطر الإنذار الكاذب: ضبط الخصوصية، المشفّر/الماحي، ماسح الشبكة المحلية، فاحص التصلب، فرز السجلات. تُعاد بعد التوقيع.

### ما يحتاج المالك فعله بنفسه

- فتح حساب Microsoft Store إن أراد النشر هناك.
- شراء شهادة توقيع OV (أو قبول SmartScreen مؤقتًا مع عرض SHA-256 بوضوح، كما هو الآن).
- تقرير الإنذارات الكاذبة إلى Microsoft Defender عند ظهورها.
- (أُلغي) أرشفة مستودع `netsecatlas-apps`: المالك طلب تركه كما هو.

## 2) المحتوى / Content calendar

### بقي من الخطة بعد الدفعة 10 (لم يُكتب بعد)

المواضيع التالية اقترحت كدفعة 11، بعربية + إنجليزية مستقلة، بنفس أسلوب الدفعة 10 (FAQ، مراجع رسمية، حد الكلمات، فرع → دمج → تحقق حي):

- تشخيص نفق VPN/IPsec عندما يسقط
- أخطاء Kerberos الشائعة
- مشاكل تجوال Wi-Fi (roaming)
- استرداد مفتاح BitLocker
- استثناءات Microsoft Defender بشكل آمن

وكذلك، عند مناسبة كل مقال قديم: إضافة روابط داخلية إلى مقالات الدفعة 10 (مثل دليل VLAN → ورقة CIDR، أحداث ويندوز → قفل الحساب 4740، دليل PowerShell → أوامر الشبكة).

صفحات البدائل: حاليا صفحتان فقط (FortiGate وPalo Alto). يمكن توسيعها لاحقًا (Cisco، Check Point، Splunk، إلخ) بعد مراجعة بشرية للمحتوى الحالي.

### مراجعة تقنية وبشرية (أولوية)

كل المحتوى المكتوب بمساعدة الذكاء الاصطناعي معلّم أنه يحتاج مراجعة. لا تُضبَط `translationStatus: reviewed` ولا `humanReviewedBy` إلا بعد أن يراجع شخص مُسمّى النصين. ابدأ بالدفعة 10 والأدلة الأساسية والمقارنات الأكثر زيارة.

### أفكار محتوى لاحقة

مراقبة الشهادات في المؤسسة، أخطاء Kerberos التفصيلية إن لم تُغطَّ بالكامل، سياسات USB، عزل شبكة الضيوف بعمق، تمارين طاولة للاستجابة للحوادث، وموضوعات عليها طلب بحث بعد النظر في Search Console (عندما تُربَط).

## 3) الموقع التقني / Site follow-ups

- **قاعدة: كل نشر يحدّث خريطة الموقع تلقائيًا.** `sitemap.xml` و`video-sitemap.xml` وRSS تُولَّد في `pnpm run build` من المقالات والمقارنات والفيديو والبدائل و`/tools` ومسارات التطبيق الجديدة. `<lastmod>` من تاريخ تحديث العنصر أو آخر commit في git (سير النشر يستخدم `fetch-depth: 0` لهذا). صفحات noindex مثل `/search` والتحويلات فقط تُستبعد. اختبار `test:build-output` يفشل إذا نقصت صفحة قابلة للفهرسة من الخريطة أو إذا ذكرت الخريطة رابط تحويل أو noindex (ما لن يكون 200 مفهرسًا). لا تُحرَّر الخريطة يدويًا.
- التحقق بعد كل نشر أن `/ar/alternatives` و`/en/alternatives` و`/tools` تعمل (أُصلح كسر البناء في 22 نوفمبر لهذا السبب)، وأن الخريطة الحيّة تضمّها ولا تضم `/search`.
- إعادة صياغة روابط المقالات التي ما زالت تشير إلى `/tools/spf-record-analyzer` ونظائرها، لتشير إلى أداة حقيقية على أداتي متى وُجدت، أو إلى تطبيق سطح المكتب للحسابات الشبكية. حاليًا هذه الروابط تُحوَّل إلى `/tools` حتى لا تُكسر.
- صفحة `/tools`: تم توحيدها في 22 نوفمبر (البرنامج الموحّد أولًا، ثم تطبيقات Atlas، ثم أداتي).
- فحص الروابط (404) تم في 22 نوفمبر على كل روابط خريطة الموقع وكل الروابط الداخلية عربي وإنجليزي. يُعاد بعد كل دفعة محتوى كبيرة.
- عدم إعادة بناء أدوات ويب داخل هذا الموقع ما دام المالك يعتمد أداتي لذلك.
